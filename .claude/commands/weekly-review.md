Run my **weekly review**.

1. Read all of `todo/areas/`, the recent files in `todo/daily/`, `todo/dashboard.md`, and the "Later / someday" section.
2. Create a review file at `todo/weekly/<this Monday's date>.md` from `todo/templates/weekly-review.md`.
3. Help me fill it in: area health table, wins, what's stuck, triage actions, and a proposed focus for next week. Ask me where you need my judgment.
4. Apply the outcomes: re-prioritize each area's next action, move stale items to "Later / someday", clear the inbox, and refresh `todo/dashboard.md`.
5. Summarize the week and next week's focus in a few lines.
