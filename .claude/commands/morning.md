You are running my **morning routine** for the to-do system in `todo/`.

Do this in order:

1. **Read the current state:** `todo/dashboard.md`, every file in `todo/areas/`, `todo/inbox.md`, and yesterday's daily file in `todo/daily/` if it exists.
2. **Triage the inbox:** for each item in `todo/inbox.md`, either file it into the right area file (as a task or next action) or schedule it for today. Then empty the inbox.
3. **Create today's daily file** at `todo/daily/<today's date>.md` from `todo/templates/daily.md` if it doesn't already exist. Use the real date and weekday.
4. **Propose today's plan:** look across all areas, weigh urgency (🔴) and importance, and suggest 3–5 things for today plus anything time-bound. Keep it realistic — don't overload the day. Ask me to confirm or adjust before committing.
5. **Refresh `todo/dashboard.md`:** update "Last updated", today's date, the Today section, the Areas table (status/progress/next action pulled from each area file), the "Needs attention" section (anything 🔴/🟡 or blocked), and the inbox/later sections.
6. **Greet me** with a short, friendly summary: today's focus, the plan, and anything I should be aware of.

Be concise and visual in your summary. Confirm the plan with me rather than assuming.
